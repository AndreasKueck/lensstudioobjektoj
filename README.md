Tio chi estas la Lens-Studio-pakajho por Snapchat-lenso "[Objektoj](https://www.snapchat.com/lens/6e0e3f071a0e41699d6a210516708f96)". Ghi prezentas la situojn de la tri Zamenhof/Esperanto-objektoj plej proksimaj al la uzanto.

Por krei Snapchat-lenson saman au similan, oni procedu jene:

1. Startigu Lens Studio.
2. Konservu tie la defaultan projekton kun ajna nomo, ekzemple nomo123. (Ghi estas uzata en la sekva priskribo.)
3. Klaku al Asset Library en Lens Studio.
4. Serchu tie lau Github Konnect en Lens Studio.
5. Instalu ghin en Lens Studio.
6. Klaku tie al Github Konnect.
7. Eventuale estas necese antaue instali [Git](https://git-scm.com/download/win) en sia komputilo, por ke `git`-komandoj funkciu.
8. En la Git Terminal de Lens Studio enigu `git clone https://github.com/AndreasKueck/lensstudioobjektoj.git` kaj klaku al `Run Git Command`.
9. Tio efikas, ke en via en-komputila projekto-dosierujo nomo123 ekestas dosierujo lensstudioobjektoj, en kiu sin trovas interalie dosiero nome lensstudioobjektoj.esproj.
10. Ghin malfermu en Lens Studio (per `File > Open Project`), modifu kaj laubezone konservu sub alia nomo.
